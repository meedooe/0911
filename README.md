# 극블리 소서 파밍 대시보드 (D2R)

로컬 전용 웹 대시보드. `index.html`을 브라우저로 열면 끝. 설치·빌드·서버 필요 없음.

## 기능
| 탭 | 내용 |
|---|---|
| 공포의 영역 | 극블리 소서 기준 맵 티어(S/A/B/D) + 파밍 효율 점수. "냉기 파괴참 보유" 토글에 따라 티어가 재평가된다. |
| 랩타임 | 런 시작 → 랩 기록 반복. 평균·최고·시간당 런 수·최근 3런 추세 자동 계산. |
| 현상수배 | 졸업 장비 23종 체크리스트 + 진행률. 부위 필터, 획득 숨기기 지원. |
| 치트시트 | FCR 프레임 계산 + 블리자드 딜 계산기 + 룬 수요 등급표. |

기록은 브라우저 localStorage에만 저장된다. 외부로 나가는 통신은 없다.

## 공략서 (guide.html)
`guide.html`은 대시보드와 별개로 도는 **단일 파일 공략 문서**다. 역시 더블클릭하면 끝.

| 섹션 | 내용 |
|---|---|
| 지금 막힌 곳 | 현재 진행도(지옥 3막 박피자의 정글)에서 막힌 원인과 응급 처치 |
| 경로 선택 | 도박 / 악몽 두 갈래 체크리스트. 진행률은 localStorage에 저장된다 |
| 진단 · 난이도 · 냉기 면역 | 지옥 저항 패널티와 면역 판정 규칙, 면역을 깨는 수단과 못 깨는 수단 |
| 해법 · 파밍 루트 · 공포의 영역 | `computeZoneScore()`로 실제 계산한 지역 점수 14+1곳. 칩으로 "지금 갈 수 있는 곳"만 걸러 볼 수 있다 |
| 졸업 장비 · 룬 | 카드마다 「확보함」 체크 (현상수배 보드처럼 사용) |
| 치트시트 · 계산기 · 도박 | FCR/FHR/FBR 표 + 저항 계산기 + FCR 브레이크포인트 체커 + 기드 도박 안내 |

상단 바에서 테마(자동/밝음/어두움)를 바꾸고, 저장된 체크 기록을 한 번에 지울 수 있다.
**파괴참 패널티처럼 검증되지 않은 수치는 계산기 입력값으로 비워뒀다.** 지어내지 않는다.

## 구조
```
index.html        마크업 뼈대
css/style.css     스타일 (색은 :root 변수로만 수정)
guide.html        단일 파일 공략서 (대시보드와 독립. CSS/JS 전부 내장)
js/01-state.js    상태 STATE + localStorage 어댑터
js/02-data.js     ★ 정적 메타 데이터 — 아이템/맵 추가는 여기만 고치면 된다
js/03-logic.js    순수 계산 함수 (DOM 접근 금지)
js/04-render.js   DOM 렌더링 전담
js/05-main.js     초기화 + 이벤트 바인딩
test/logic.test.mjs
```

**유지보수 규칙은 `CLAUDE.md`에 전부 있다.** 경량 모델에 넘기기 전에 그 파일을 먼저 읽히면 된다.

## 주의
- 거래 **가격/시세는 의도적으로 넣지 않았다.** 시즌마다 변해서 하드코딩하면 금방 거짓말이 된다. 상대 수요 등급(T0~T3)만 유지한다.
- 블리자드 딜 계산기의 기본 데미지는 위키 앵커값 사이 **선형 보간 근사치**다. 정확한 값은 인게임 스킬창에서 확인해라.
- 면역 몬스터의 저항 감소 적용률(20%)과 파괴참 후 저항(95%)은 커뮤니티 통용값이다. 패치로 바뀔 수 있고, `META_DATA.blizzard`에서 한 줄로 고칠 수 있게 빼놨다.
